## 8. Conclusions

Decision: `failed`.

This run neither establishes nor refutes the full published GDN MQAR result.
Seven cells are valid partial observations, but the experiment's declared unit
was the complete 12-cell suite. Cell07's failed terminal triggered the
predeclared stop rule, so it was not retried and cells08–11 were not launched.

The failure was an orchestration fault, not a model result: both source and
runtime checks passed, but setup consumed the narrow lease margin between two
time checks. A future, separately approved suite should require additional
launch slack at least as large as worst-case setup and validation time. That
repair is not applied retroactively here.

The Bitter Lesson says, in broad terms, that scalable learning and computation
tend to beat hand-written task tricks over the long run. This reproduction kept
the published learnable model and grid unchanged; the compatibility wheel,
cache prewarm, and lease checks controlled the measurement rather than feeding
task knowledge to the model. The no-retry decision is preregistered experiment
discipline, not an implication of the Bitter Lesson. Because the suite did not
finish, this experiment cannot support or challenge the Bitter Lesson.

Plain-language glossary:

- **Cell**: one training run for one width and one learning rate.
- **Suite**: the fixed set of all 12 cells.
- **Controller / worker**: the controller checks whether a cell may be
  launched; the worker is the separate process that repeats the checks and
  would perform training.
- **Admission check**: a pre-run check that enough AIStation lease time remains
  to finish safely.
- **Adjusted seconds / frozen floor**: adjusted seconds are the reported lease
  time minus the age of that report; the frozen floor is the minimum value
  declared before training, here 11,460 seconds.
- **Fail closed**: stop when a safety condition is uncertain or false instead
  of silently changing the experiment.
- **Cell contract**: automated checks that one run used the expected source,
  configuration, data cache, runtime, paths, and complete output files.
- **Frontier**: for each width, choose the largest final accuracy among the four
  learning rates.
- **Best diagnostic**: the highest validation value seen during training; it
  is reported for diagnosis but does not select the frontier.
- **Raw delta**: reproduced accuracy minus the value read from the official
  plot, before applying the acceptance band.
- **Plot reading**: a two-decimal value read from the published PNG because the
  exact W&B value is unavailable.
- **State-size proxy**: Zoology's formula-based estimate of recurrent-state
  bytes at sequence length 1024; it is not measured GPU memory or parameter
  count.
- **Inventory / closeout manifest**: SHA-256 lists that bind every archived
  suite file and every separate failure-evidence file, so later readers can
  detect missing or changed bytes.
- **Configuration-level reproduction**: evidence that the published
  configuration gives the same broad result within a declared band. This
  failed suite cannot make that claim.
